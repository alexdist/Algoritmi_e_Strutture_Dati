TRACCIA

Risolvere il problema della selezione di attività utilizzando
una coda di min-priorità.


ALGORITMO DI BASE UTILIZZATO: ACTIVITY SELECTION GREEDY CON CODA DI MIN-PRIORITÀ


ACTIVITY-SELECTION-MIN-PRIORITY(S, F)

    n <- S.length                              // Numero totale di attività

    A <- insieme vuoto                         // Insieme delle attività selezionate

    Q <- coda di min-priorità vuota            // Creo la coda di min-priorità

    for i <- 1 to n                            // Scorro tutte le attività
        MIN-HEAP-INSERT(Q, (i, f[i]))          // Inserisco attività i con chiave pari al tempo di fine f[i]

    k <- EXTRACT-MIN(Q)                        // Estraggo l'attività con tempo di fine minimo

    A <- A ∪ {k}                               // Seleziono la prima attività

    while Q != insieme vuoto                   // Continuo finché la coda non è vuota

        m <- EXTRACT-MIN(Q)                    // Estraggo l'attività con tempo di fine minimo

        if s[m] >= f[k]                        // Controllo se m è compatibile con l'ultima attività scelta

            A <- A ∪ {m}                       // Aggiungo m alle attività selezionate

            k <- m                             // m diventa l'ultima attività selezionata

    return A                                   // Restituisco il massimo insieme di attività compatibili



MIN-HEAP-INSERT(Q, key)

    Q.heapsize <- Q.heapsize + 1               // Creo spazio per il nuovo elemento

    Q[Q.heapsize] <- +∞                        // Inserisco temporaneamente +∞

    HEAP-DECREASE-KEY(Q, Q.heapsize, key)      // Inserisco la nuova chiave nella posizione corretta



HEAP-DECREASE-KEY(Q, i, key)

    if key > Q[i]                              // Controllo che la nuova chiave non sia maggiore

        error "invalid data"                   // Segnalo un aggiornamento non valido

    Q[i] <- key                                // Assegno la nuova priorità

    while i > 1 AND Q[PARENT(i)] > Q[i]        // Risalgo finché il padre ha priorità maggiore

        scambia Q[PARENT(i)] con Q[i]          // Scambio figlio e padre

        i <- PARENT(i)                         // Aggiorno la posizione nell'heap


COMPLESSITA'

La coda di min-priorità contiene le n attività.

Una singola MIN-HEAP-INSERT costa:

O(log n)

Poiché inseriamo tutte le n attività, il costo complessivo
per costruire la coda è:

O(n log n)


Una singola EXTRACT-MIN costa:

O(log n)

Nel caso peggiore estraiamo tutte le n attività dalla coda,
quindi il costo complessivo delle estrazioni è:

O(n log n)


I controlli di compatibilità e gli inserimenti nell'insieme A
richiedono tempo costante O(1) per ogni attività, quindi
complessivamente:

O(n)


Quindi:

O(n log n) + O(n log n) + O(n)

La complessità totale è:

O(n log n)
