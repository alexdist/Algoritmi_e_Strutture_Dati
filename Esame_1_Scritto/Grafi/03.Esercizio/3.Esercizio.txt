TRACCIA

Dato un grafo connesso orientato G=(V,E) con funzione peso w:E→R ed un vertice r∈V,
si scriva un algoritmo (in pseudocodice) che restituisca l'altezza dell'albero
dei cammini minimi.


PSEUDOCODICE

ALTEZZA-ALBERO-CAMMINI-MINIMI(G, w, r)

    INITIALIZE-SINGLE-SOURCE(G, r)          // Inizializzo d[r]=0, gli altri d[v]=∞ e π[v]=NIL

    for i <- 1 to |V|-1                    // Bellman-Ford esegue |V|-1 iterazioni
        for ogni arco (u,v) ∈ E[G]         // Scorro tutti gli archi del grafo
            RELAX(u,v,w)                    // Provo a migliorare d[v] passando attraverso u

    for ogni arco (u,v) ∈ E[G]             // Eseguo una scansione aggiuntiva degli archi
        if d[v] > d[u] + w(u,v)            // Se un arco è ancora rilassabile, esiste un ciclo negativo
            return NULL                     // L'albero dei cammini minimi non è definito

    for ogni v ∈ V[G]                      // Inizializzo la lista dei figli di ogni vertice
        figli[v] <- lista vuota            // Inizialmente ogni vertice non ha figli

    for ogni v ∈ V[G]                      // Scorro tutti i vertici
        if π[v] != NIL                     // Se v possiede un padre nell'albero dei cammini minimi
            aggiungi v a figli[π[v]]        // v diventa figlio del proprio predecessore π[v]

    return HEIGHT(r)                        // Calcolo l'altezza dell'albero a partire dalla radice r


HEIGHT(x)

    if figli[x] è vuoto                    // Se x è una foglia
        return 0                            // Una foglia ha altezza 0

    h <- 0                                 // Memorizzo la massima altezza trovata

    for ogni y ∈ figli[x]                  // Scorro tutti i figli di x
        h <- max(h, 1 + HEIGHT(y))          // Considero l'arco x->y più l'altezza del sottoalbero di y

    return h                               // Restituisco l'altezza massima del sottoalbero di x


COMPLESSITA'

Bellman-Ford esegue |V|-1 iterazioni e ad ogni iterazione scorre tutti gli archi:

O(|V| * |E|)

La scansione aggiuntiva degli archi per verificare la presenza di un ciclo negativo costa:

O(|E|)

L'inizializzazione delle liste dei figli e la costruzione dell'albero dei cammini minimi costano:

O(|V|)

La funzione HEIGHT visita ogni vertice dell'albero una sola volta:

O(|V|)

Quindi:

O(|V| * |E|) + O(|E|) + O(|V|) + O(|V|)

La complessità totale è:

O(|V| * |E|)
