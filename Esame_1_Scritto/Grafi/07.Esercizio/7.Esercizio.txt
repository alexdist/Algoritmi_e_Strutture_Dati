TRACCIA

Riscrivere l'algoritmo di Kruskal utilizzando una coda di min-priorità.


ALGORITMO DI BASE UTILIZZATO: KRUSKAL CON CODA DI MIN-PRIORITÀ E UNION-FIND


PSEUDOCODICE

KRUSKAL-MIN-PRIORITY-QUEUE(G, w)

    A <- insieme vuoto                          // Insieme degli archi che formeranno l'MST

    for ogni v ∈ V[G]                          // Scorro tutti i vertici del grafo
        MAKE-SET(v)                             // Ogni vertice appartiene inizialmente a un insieme separato

    Q <- coda di min-priorità vuota             // Creo la coda che conterrà gli archi del grafo

    for ogni arco (u,v) ∈ E[G]                  // Scorro tutti gli archi del grafo
        MIN-HEAP-INSERT(Q, ((u,v), w(u,v)))     // Inserisco l'arco con chiave pari al suo peso

    while Q != insieme vuoto AND |A| < |V|-1    // Continuo finché la coda non è vuota e l'MST non è completo

        (u,v) <- EXTRACT-MIN(Q)                 // Estraggo l'arco con peso minimo

        if FIND-SET(u) != FIND-SET(v)            // Controllo se u e v appartengono a componenti diverse

            A <- A ∪ {(u,v)}                    // Aggiungo l'arco all'MST

            UNION(u,v)                           // Unisco le due componenti

    return A                                     // Restituisco gli archi dell'MST



MIN-HEAP-INSERT(Q, key)

    Q.heapsize <- Q.heapsize + 1                // Aumento la dimensione dell'heap

    Q[Q.heapsize] <- +∞                         // Inserisco temporaneamente +∞ nell'ultima posizione

    HEAP-DECREASE-KEY(Q, Q.heapsize, key)       // Assegno la nuova chiave e ripristino il min-heap



HEAP-DECREASE-KEY(Q, i, key)

    if key > Q[i]                               // Controllo che la nuova chiave non sia maggiore
        error "invalid data"                    // Segnalo un aggiornamento non valido

    Q[i] <- key                                 // Assegno la nuova chiave

    while i > 1 AND Q[PARENT(i)] > Q[i]         // Continuo finché il padre ha chiave maggiore

        scambia Q[i] con Q[PARENT(i)]           // Scambio il nodo con il padre

        i <- PARENT(i)                          // Continuo dalla nuova posizione del nodo




COMPLESSITA'

L'inizializzazione degli insiemi disgiunti tramite MAKE-SET richiede:

O(|V|)


La coda di min-priorità contiene gli archi del grafo.

Una singola MIN-HEAP-INSERT costa:

O(log |E|)

Poiché inseriamo tutti i |E| archi, il costo complessivo degli inserimenti è:

O(|E| log |E|)


Nel caso peggiore il ciclo while può esaminare tutti i |E| archi.

Una singola EXTRACT-MIN costa:

O(log |E|)

Quindi tutte le estrazioni costano complessivamente:

O(|E| log |E|)


Utilizzando Union-Find con union by rank e path compression,
le operazioni FIND-SET e UNION hanno complessità ammortizzata
legata alla funzione inversa di Ackermann.

Complessivamente questa parte costa:

O(|E| α(|V|))


Quindi:

O(|V|) + O(|E| log |E|) + O(|E| log |E|) + O(|E| α(|V|))


Il termine dominante è:

O(|E| log |E|)


La complessità totale è quindi:

O(|E| log |E|)
