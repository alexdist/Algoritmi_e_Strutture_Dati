TRACCIA

Dato un grafo orientato G = (V,E), rappresentato mediante una lista
di adiacenza, scrivere un algoritmo in pseudocodice che restituisca
la lista di puntatori ai vertici di G di grado massimo.
Analizzare la complessità nel caso peggiore.


ALGORITMO DI BASE UTILIZZATO

Scansione delle liste di adiacenza.

Il grado uscente di ogni vertice u viene calcolato contando
il numero di elementi presenti in Adj[u].

L'algoritmo esegue due passate:
- nella prima determina il grado massimo;
- nella seconda costruisce la lista dei puntatori ai vertici
  che possiedono tale grado.


PSEUDOCODICE

VERTICI-GRADO-MASSIMO(G)

    for ogni v ∈ V[G]                         // Inizializzo il grado di ogni vertice
        count[v] <- 0                         // Inizialmente ogni grado vale 0

    for ogni u ∈ V[G]                         // Scorro tutti i vertici del grafo
        for ogni v ∈ Adj[u]                   // Scorro tutti gli adiacenti di u
            count[u] <- count[u] + 1          // Incremento il grado uscente di u

    maxGrado <- 0                             // Inizializzo il grado massimo

    for ogni v ∈ V[G]                         // Scorro tutti i vertici
        if count[v] > maxGrado                // Controllo se trovo un grado maggiore
            maxGrado <- count[v]              // Aggiorno il grado massimo

    L <- lista vuota                          // Creo la lista risultato

    for ogni v ∈ V[G]                         // Scorro nuovamente tutti i vertici
        if count[v] = maxGrado                // Controllo se v ha grado massimo
            INSERISCI(L, ptr(v))              // Inserisco nella lista il puntatore a v

    return L                                  // Restituisco la lista dei puntatori


COMPLESSITA'

Inizializzazione di count:

    O(V)

Scansione delle liste di adiacenza:

    O(V + E)

Ricerca del grado massimo:

    O(V)

Costruzione della lista risultato:

    O(V)

Quindi:

    O(V) + O(V + E) + O(V) + O(V)

COMPLESSITA' TOTALE:

    O(V + E)

Tempo: O(V + E)

Spazio ausiliario: O(V)
